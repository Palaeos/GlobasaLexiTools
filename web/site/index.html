Globasa Translator

Rule-based machine translation between Globasa and six languages, running entirely in your browser: the Apertium pairs are compiled to WebAssembly and loaded into memory, so nothing you type leaves this page.

About this translator

Each direction is an Apertium pair. Its processors (lt-proc, cg-proc, apertium-tagger, lrx-proc, lsx-proc, apertium-anaphora, rtx-proc) run as one WebAssembly binary, and the pairs' own Python steps run unchanged in Pyodide. The output is the same, byte for byte, as the native pipeline with its neural steps switched off.

Neural steps. On a desktop setup some directions (into Globasa from English, French, Spanish, German and Dutch) also use local NLP models for tagging, coreference and gender. Those are too large for a browser, so here those stages are skipped and the rule-based behaviour is used; each skipped stage is listed under the translation.
